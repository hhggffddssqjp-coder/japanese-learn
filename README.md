# にほんご冒險 — 闖關式日語學習

給繁體中文使用者的日語學習網站／PWA，電腦與手機都能用。純前端、不需安裝或建置，進度存在瀏覽器本機。

## 特色

- **闖關地圖**：7 個世界、89 個關卡——はじめまして（零基礎入門）→ ひらがな → カタカナ → 濁音・拗音 → N5 基礎單字 → N5 日常生活 → N4 進階表達。每個世界最後有「鬼關」（3 顆心），通關可蓋下朱印
- **單字圖例**：每個單字（約 200 個）都有圖片、例句、記憶口訣；每個假名都有「圖例字」（あ＝☔あめ）幫助聯想記憶
- **零基礎入門**：連五十音都不會也能開始——先用 4 頁小卡片認識文字與五十音圖（含注音對照），再每關只學 2～3 個母音，並有複習與母音鬼關
- **依程度出題**：首次進入可選程度或做 12 題程度測驗；每個世界可用「跳級挑戰」直接解鎖；題型由易到難（看圖選字 → 聽音選字 → 例句填空 → 排列句子 → 輸入拼音）
- **語音**：使用瀏覽器內建 Web Speech API（ja-JP）即時產生發音，支援慢速、自動播放、聽力題與聽力特訓
- **成就感系統**：經驗值與等級、每日連勝（含連勝凍結）、答題連擊、三星評價、每日目標、成就徽章、朱印帳、單字圖鑑（未收集顯示為剪影）、櫻花紙吹雪與音效
- **記憶科學**：間隔重複（SRS）每日複習、弱點加強、閃電挑戰
- **PWA**：可加入主畫面、離線使用；深色模式；可匯出／匯入進度

## 執行

```sh
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

## 部署（GitHub Pages）

Settings → Pages → Deploy from a branch → 選擇分支與 `/ (root)`。所有路徑皆為相對路徑。

## 結構

| 檔案 | 說明 |
| --- | --- |
| `index.html`, `css/style.css` | 頁面骨架與樣式（和紙＋朱印風格、深色模式、響應式） |
| `js/data-kana.js` | 假名與圖例字 |
| `js/data-words.js` | 單字課（圖、例句、口訣） |
| `js/data-grammar.js` | 文法課（N5 10 課、N4 6 課） |
| `js/core.js` | 進度儲存、等級／連勝、SRS、語音、音效、羅馬拼音 |
| `js/curriculum.js` | 世界與關卡組成、解鎖與跳級 |
| `js/questions.js` | 題型產生器與出題規劃 |
| `js/player.js` | 教學卡、答題、回饋、結算畫面 |
| `js/views.js`, `js/ui.js`, `js/app.js` | 地圖／圖鑑／練習／個人頁、對話框與特效、啟動 |

## 擴充內容

- 新增單字：在 `js/data-words.js` 某一課的 `words` 加一行 `[日文, 讀音, 中文, 圖, 例句, 例句中文, 口訣]`（例句以 `|` 分詞、`漢字{讀音}` 標注振假名）
- 新增一課：在 `lessons` 加物件，再於 `js/curriculum.js` 的 `seq(...)` 排進關卡
- 新增文法：在 `js/data-grammar.js` 加物件，並於 `seq(...)` 以 `g:id` 排入

## 語音說明

發音取決於裝置是否有日語語音。找不到日語語音時，聽力題會自動略過；「我的」頁面有各系統安裝日語語音的說明。
