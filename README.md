# にほんご 日語學習

給繁體中文使用者的日語學習網頁 App。純前端、不需安裝或建置，進度存在瀏覽器本機。

## 功能

- **五十音**：平假名／片假名表（清音、濁音、拗音），點擊發音；可練習「看假名選拼音」「看拼音選假名」「輸入拼音」，並記錄弱點假名
- **單字記憶卡**：約 120 個 N5 基礎單字，間隔重複（SRS）排程，每日新單字數可調整
- **單字測驗**：看字選義、選日文、聽音選義
- **文法課**：10 堂基礎文法（は／か／の／を／ます形／に・で・へ／形容詞／あります・います／〜たい／て形），含例句發音與小測驗
- **進度**：經驗值、等級、連續學習天數、每日目標；可匯出／匯入進度；淺色／深色主題
- **PWA**：可加入手機主畫面，支援離線使用（需透過 http(s) 提供）

## 執行

```sh
python3 -m http.server 8000
# 然後開啟 http://localhost:8000
```

也可以直接用瀏覽器開啟 `index.html`（離線快取功能需要 http(s)）。

## 部署（GitHub Pages）

倉庫 Settings → Pages → Build and deployment：Source 選 **Deploy from a branch**，Branch 選 `main`（或要發佈的分支）、資料夾選 `/ (root)`，儲存後約 1 分鐘上線，網址為 `https://<帳號>.github.io/japanese-learn/`。所有路徑皆為相對路徑，可直接放在子路徑下。

## 結構

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 頁面骨架 |
| `style.css` | 樣式（含深色模式、手機版面） |
| `data.js` | 五十音、單字、文法課內容 |
| `app.js` | 路由、SRS、測驗引擎、進度儲存 |
| `sw.js`, `manifest.webmanifest`, `icon.svg` | PWA 離線與安裝 |

## 擴充內容

- 新增單字：在 `data.js` 的 `raw` 對應分類加一行 `[日文, 讀音, 中文]`
- 新增文法課：在 `data.js` 的 `grammar` 陣列加入一個物件（`quiz` 每題第一個選項為正確答案）

語音使用瀏覽器內建的 Web Speech API（`ja-JP`），發音品質取決於裝置有無日語語音。
