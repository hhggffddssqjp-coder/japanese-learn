# 預錄高品質日語語音（Google Cloud，一次性，約 15 分鐘）

網站預設用裝置內建的語音，品質因手機／電腦而異。這份教學會用 Google Cloud 的類神經語音，**一次性**把所有單字、假名、例句錄成 mp3 放進網站。之後所有裝置都播同一個自然的聲音，**使用者播放時不會再呼叫 Google，不會再產生費用**。

## 費用與風險

- 全部文字約 7,000 多字元（含慢速版），**只需要錄一次**。Neural2／WaveNet 語音每月有免費額度（我印象中約 100 萬字元），本次大約只用掉 1% 以下。價格與額度會變動，請以 [Google 官方價目頁](https://cloud.google.com/text-to-speech/pricing) 為準。
- 需要綁信用卡開通帳單（無法避免）。
- 最大風險是**金鑰外洩被盜用**。請務必：金鑰只放在 GitHub Secrets、限制金鑰只能呼叫 Text-to-Speech、設預算提醒、錄完後刪除金鑰並停用 API。
- 預算提醒只會通知，**不會自動停止扣款**。

## 步驟

### 1. 建立專案並設定帳單

1. 開啟 <https://console.cloud.google.com>，右上角選單建立**新專案**，名稱例如 `nihongo-tts`（建議不要用 Firebase 的專案，避免動到它的方案）。
2. 左側選單 **帳單 (Billing)** → 連結或建立帳單帳戶（需信用卡）。
3. 帳單 → **預算與快訊 (Budgets & alerts)** → 建立預算，金額設 `1` 美元，並勾選電子郵件通知。

### 2. 啟用 API 並建立金鑰

1. **API 和服務 → 程式庫**，搜尋 **Cloud Text-to-Speech API**，按 **啟用**。
2. **API 和服務 → 憑證 → 建立憑證 → API 金鑰**。
3. 點進剛建立的金鑰 → **API 限制** → 選「限制金鑰」→ 只勾選 **Cloud Text-to-Speech API** → 儲存。
4. 複製金鑰（`AIza...`）。**不要貼在聊天室、程式碼或任何公開的地方。**

### 3. 把金鑰存進 GitHub

倉庫 **Settings → Secrets and variables → Actions → New repository secret**，名稱填 `GOOGLE_TTS_KEY`，值貼上金鑰。

（另外確認 Settings → Actions → General → Workflow permissions 沒有被限制成「唯讀」。本流程已在檔案內要求寫入權限，個人倉庫通常不用改。）

### 4. 執行產生流程

倉庫 **Actions → 產生語音檔 → Run workflow**（分支選 `main`）：

1. 第一次保持「只計算字數」勾選，執行。到結果的 Log 看「總字元」與「需新產生」，確認數字合理。
2. （選用）勾選「只列出可用的日語語音」執行，查看有哪些語音名稱可選（Neural2、WaveNet 的男聲／女聲）。
3. 取消勾選「只計算字數」，需要時改 `voice`，再執行一次。完成後會自動把 `audio/` 提交到 `main`，並觸發 Pages 重新部署。

腳本有字元上限保護（預設 60,000），超過會中止，避免意外費用。之後新增單字時再執行一次，只會補錄新增的部分。

### 5. 收尾

- 約 1～2 分鐘後，打開網站，到「我的」頁面會看到「使用預錄高品質語音」開關，按「試聽」確認。
- **確認沒問題後，到 Google Cloud 刪除金鑰，並停用 Text-to-Speech API**；GitHub 的 `GOOGLE_TTS_KEY` Secret 也可以刪掉。已經錄好的 mp3 不受影響。

## 注意

- 單獨一個假名（は、へ、を）的唸法，語音引擎可能依上下文讀成助詞（wa、e、o）。如果聽到不對，請告訴我，我再調整。
- 預錄音檔不含例句以外的臨時文字；找不到對應音檔時，網站會自動改用裝置語音。
- 音檔約 1～2 MB／千句，全部加起來遠小於 GitHub Pages 的限制。
